# 智测云 5–8 分钟演示视频脚本

建议成片约 7 分钟，1080p。其中第 6 部分专门展示 AI 协同过程，时长不少于 2 分钟。全程使用虚拟学生数据。

## 0:00–0:35｜痛点与定位

**画面：**产品首页。

**讲解：**

> 一节课结束后，教师往往需要一个快速检测，却还要手动出题、收集答案和统计正确率。智测云面向高校课堂随堂知识回顾，通过 AI 生成客观题，由教师审核发布，学生在线作答，系统自动评分并反馈知识点掌握情况。

强调：不是综合考试系统，不做图片作答或数学解答过程评阅。

## 0:35–1:35｜从课堂内容生成测验

**画面：**教师创建页。

操作：

1. 使用“机器学习导论—过拟合与模型泛化”示例；
2. 展示课堂讲义要点；
3. 选择 6 道题、四种题型、适中难度、10 分钟；
4. 点击生成。

**讲解：**

> 教师不需要逐题设计字段，只需描述教学要求。系统要求模型返回结构化 Assessment Schema，而不是直接生成网页代码。

如未配置密钥，创建页会明确提示无法生成并禁用按钮，此时应说明“需要先完成 API 配置才能演示生成”。

## 1:35–2:35｜教师审核与发布

**画面：**题目编辑页。

操作：

1. 展开并修改一道题的题干或解析；
2. 展示选择题答案设置、填空题等价答案；
3. 展示总分 100 分；
4. 保存草稿并发布；
5. 展示链接与二维码。

**讲解：**

> AI 只负责初稿，教师拥有最终审核权。每道题都带答案、解析和知识点，发布后锁定题目，保证所有学生使用同一评分标准。

## 2:35–3:40｜学生作答与即时反馈

**画面：**新窗口打开学生链接。

操作：

1. 输入“演示学生”和虚拟学号；
2. 完成选择、判断、填空；
3. 提交并展示成绩；
4. 查看一道错题的正确答案与解析。

**讲解：**

> 学生作答页不会收到标准答案。答案提交到服务端后才进行评分，因此不能通过查看前端数据直接获得答案。

## 3:40–4:35｜班级统计与导出

**画面：**教师结果页，提前准备至少两份不同成绩的提交。

操作：

1. 展示平均分、最高分、及格率；
2. 指出正确率较低的题；
3. 展示知识点反馈和学生成绩表；
4. 导出 CSV。

**讲解：**

> 系统把分数进一步转化为逐题正确率和知识点反馈，帮助教师决定下节课需要回顾什么。

## 4:35–6:45｜AI 协同过程复现（超过 2 分钟）

**画面：**AI 会话原始记录、`docs/ai-collaboration.md`、Git 提交和代码差异。

依次展示三次真实迭代：

### ① Schema 与评分内核

- 展示用户需求“选择、填空、判断，主要是回顾课堂内容”；
- 展示 AI 如何据此建立统一 Schema；
- 打开 `scoring.ts`，说明多选全对得分和填空等价答案；
- 展示测试工具原生绑定失败后改为 Node 原生测试的记录；
- 运行 `pnpm test`。

### ② 学生答案隔离

- 展示 AI 对学生端的修改意图；
- 打开 `public-quiz.ts`，说明删除了哪些字段；
- 打开对应测试；
- 展示一次真实类型错误及修复：学生组件从完整 `Question` 改为公开题目类型。

### ③ 生产构建修复

- 展示 macOS 原生 SWC 签名错误；
- 说明没有伪造“构建成功”，而是安装官方 WASM 备用编译器；
- 打开 `scripts/next.mjs`；
- 现场执行 `pnpm build`。

同时执行：

```bash
git log --oneline
```

指出每次提交对应一个真实功能演进，不是一次性提交全部代码。

## 6:45–7:20｜架构与总结

**画面：**架构文档或简洁流程图。

**讲解：**

> 智测云的核心不是简单调用一次大模型，而是用 Prompt 约束、Schema 校验、教师审核、服务端评分和测试验证构成完整闭环。AI 提高了出题效率，教师仍然掌握教学内容与评价标准。

最后展示 `README.md`，说明可在 10 分钟内安装复现。
